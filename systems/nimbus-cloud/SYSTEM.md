# Nimbus Cloud

> Original Cloud system. Binding values live in `tokens.css`.

## Product truth

Nimbus Cloud makes evidence feel tangible: a #101417 ground, #182127/#223039 elevation sequence, #EFF6F8 primary ink, #A8B8C0 supporting ink and one #63C7E6 signal accent. The display face is "Bodoni Moda"; text uses Inter Tight and data uses JetBrains Mono.

## Composition contract

The three licensed directions are `split-proof`, `rail-story`, `editorial-ledger`. Each page still needs four section shapes, two widths, one inspectable artifact and no more than two signature moments.

## Material and motion

Light enters above-left. Use the three declared elevation levels, grain on fills above 40vh, a transform-only arrival and an immediate reduced-motion state. Radius nesting is 6px → 12px → 20px.

Watch it collapse See the numbers

$ cadence ship --tag v2.4.0

The problem

Every release is the same six steps, done by hand, at the worst possible hour.

They are not hard steps. They are steps that must all happen, in order, without one being forgotten. That is a machine's job, and it has been a person's job for a decade.

Before

  1. Tag the version
  2. Write the changelog
  3. Run the build
  4. Sign the artifact
  5. Publish to the registry
  6. Announce in the channel

After

  • Tag the version
  • Write the changelog
  • Run the build
  • Sign the artifact
  • Publish to the registry
  • cadence ship

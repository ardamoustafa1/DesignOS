Text scramble

Characters resolve out of noise. Earned when the product is about data, transformation, or inference. The effect is a metaphor for the work. The real string lives in aria-label and the element reserves its width, so nothing reflows.

§4 · interaction-scale

3D tilt

The card rotates toward the cursor, capped at 6°. The inner block sits on translateZ so the text rises with the tilt instead of shearing under it.

Inspect the artefact

Earned only when the card holds something worth turning over: a screenshot, real data, a physical object. Tilting a text card is theatre.

Odometer

Digits roll like a mechanical counter and settle left to right. tabular-nums is load-bearing: proportional digits change the element width as they roll and the layout jitters.

§9 · hero-scale

Noise canvas field

Atmosphere without a WebGL dependency: hash-based value noise on a 2D canvas at half resolution, with an IntersectionObserver and a visibilitychange guard. Both guards are load-bearing; remove either and this is why a laptop fan spins up.

paused off-screen and on hidden tabs

§10 · interaction-scale

Liquid morph

A hexagon flows into a rectangle as the panel opens: the same object, two states. clip-path interpolates natively when both polygons have the same vertex count; mismatched counts cut instead of morphing.

Morph the element the user clicked. That is the thread of continuity. Everything else crossfades.

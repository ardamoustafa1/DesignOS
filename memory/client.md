# Client

- Project: DesignOS open-source design-intelligence operating system.
- Owner: Arda Moustafa.
- Primary audience: developers and coding-agent users who need production-grade interface judgment, implementation recipes, and verifiable gates.
- Current objective (2026-08-19): productize DesignOS as a keyless, centrally orchestrated design-generation studio that accepts a brief, applies a selected system, generates an animated prototype, withholds it until a measurable quality gate passes, and later exposes the same workflow to 25+ coding agents through MCP.
- Owner approved the architecture, quality contract, and roadmap on 2026-08-19. The Studio MVP is implemented under `studio/`; provider credentials remain operator-owned server secrets and end users never enter model-provider keys.
- One-reader sentence: Let a developer or coding-agent user move from a brief to a demonstrably high-craft, animated, production-ready artifact without managing model credentials or trusting an unverified self-score.
